### Fontra Hive — the collaborative font editor

<a href="https://fontrahive.com"><img src="https://raw.githubusercontent.com/Uplus-Type/fontra-hive/main/src/fontra_hive/client/icons/hive-icon.svg" alt="Fontra Hive" width="64" align="left"></a>

[**fontrahive.com**](https://fontrahive.com) · beta, by invitation

A hosted, collaborative workspace for type teams, built on
[Fontra](https://fontra.xyz), the open-source, browser-based font editor:
per-glyph history, snapshots, editing together, import and download.

### Open source

- [**fontra-hive**](https://github.com/Uplus-Type/fontra-hive) — the Fontra plug-in behind Fontra Hive: git-backed projects, glyph history, collaboration (GPLv3)
- [**hangul-explorer**](https://github.com/Uplus-Type/hangul-explorer) — navigate the Hangul character set through its jamos ([try it](https://uplus-type.github.io/hangul-explorer/)) (Apache 2.0)
